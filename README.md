# React Company Dashboard

Одностраничное приложение для управления списком компаний и их сотрудников, разработанное с использованием **React**, **Redux Toolkit**, **TypeScript** и **Vite**. Проект реализует функциональность без сторонних UI-библиотек — таблицы и поведение построены вручную.

## 🚀 Возможности

- 📋 Таблица компаний с чекбоксами и выделением строк.
- 👥 Таблица сотрудников выбранной компании.
- ✏️ Редактирование данных прямо в таблицах (кроме счётчика сотрудников).
- ➕➖ Добавление и удаление компаний и сотрудников.
- 🔄 Автоматическое обновление счётчика сотрудников.
- 🧠 Хранение данных в Redux Store.
- 📐 Реализация с минимумом сторонних зависимостей.
- 📈 Опционально: поддержка работы с большими объёмами данных (10 000+ строк) через динамическую подгрузку.
